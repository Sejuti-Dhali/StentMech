# StentMech
Report-based interactive portfolio of Palmaz–Schatz stent expansion using original group-project figures and Tables 1–3. Open `index.html` locally or deploy the repository root using GitHub Pages. No dependencies.

## Provenance
Original group 2 stent report, KUET; supervisors Jeba Fairooz Rahman and Kazi Jannatul Ferdowshee. Confirm permission from group members before public release and add complete contributor credits.

## Limitations
No CAD/COMSOL source or new solver runs. Stress estimates converted from 10^8 Pa to MPa. Negative foreshortening denotes elongation in the source. Density values are unverified, particularly tantalum. Cobalt stress follows Table 2. Original figures are retained without digitizing pressure curves. Educational only.
